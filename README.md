# AutomaticTestPrinting

特訓レポートから確認テストの作成依頼を読み取り、既存のExcelマクロとPDF教材を使って問題・解答を準備するWindowsデスクトップアプリです。

## 現在の範囲

初期版では以下を実装しています。

- OneDrive内の教材フォルダー設定
- Google Drive（マイドライブ）の未処理フォルダーからレポートPDFを一括読込
- 同期直後・空ファイル・重複ファイルの除外
- 作成結果の出力フォルダー設定
- 複数の特訓レポートPDF選択
- 選択内容の事前検査
- 設定のローカル保存
- Windows標準OCRによるレポート読み取り（追加料金なし）
- 0度・180度の自動向き判定
- 生徒名、通常テスト依頼、段階突破テスト依頼の確認表示
- OCR座標を使った通常テストの教材名・範囲・問題数の列解析
- 読み取り結果から原本PDFを開く確認導線
- OCRで読み取った生徒名・教材名・開始番号・終了番号・問題数の画面修正と即時再検査
- レポート単位・テスト単位のスキップ、エラー・未対応教材の一括スキップ
- 要確認項目だけの絞り込み表示
- 大量レポート向けの2件並行OCRと進捗件数表示
- スキップした生徒・レポート・教材・範囲・理由のCSVログ保存（PDF作成時は自動保存）
- 読み取り・事前検査・PDF作成エラーの対象情報、エラーコード、内部詳細をCSVへ自動保存
- ターゲット1900（6訂版）、英検準1級単熟語EX（第2版）、英熟語ターゲット1000（5訂版）、Vintage（4th Edition）、国語力を伸ばす 語彙1700（シグマベスト）、速読英熟語（新版・改訂版）、共通テスト 公共・政治経済 集中講義（五訂版）のExcel連携
- 教材名の空白・括弧・全角半角などの表記ゆれを吸収
- 範囲・問題数・ファイル存在の事前検査（Vintageは最大100問で1ページ25問、速読英熟語はテーマ番号指定・最大50問）
- 問題番号を基準に原本の問題解答リストを照合し、問題文と解答の取り違えを防止
- 元のExcelを変更せず、対応教材の問題PDF・解答PDFを個別に作成
- 原本確認チェックと作成前の最終確認（実プリンターへの送信なし）
- 既存教材と同じExcel形式の教材を画面から追加登録
- PDF教材の手動ページ抽出・分割済みPDFの結合・段階突破PDFの全ページ利用
- PDF教材の問題／解答別の一括PDFと、両面印刷時のファイル境界への白紙挿入
- PDF教材の問題番号・ファイル名・ページ対応表の登録／編集と永続保存
- レポートの範囲から登録済みPDF教材を抽選・抽出し、Excel教材と同じ一括PDFへ結合
- 科目・年度・段階・回を含む段階突破テスト依頼のPDF照合（原本確認必須）

## PDF教材の登録と自動作成

### 共通教材カタログ

右上の「教材カタログ」からExcel・通常PDF・段階突破を横断検索できます。
指定フォルダー限定のカタログに、追加段階突破と「Excel」シートの手動調査情報を統合しています。
2026-10-08のExcelシート103行は、既存19件への調査メモ追記と追加84候補として反映しました。
教材名の食い違い・ファイル未特定の10行は登録保留です。
共有ページがある通常PDFは、問題とページの対応表がある場合に出力できます。複合番号のPDFや未設定のExcel形式は登録内容を確認してください。
既存のExcel設定・校舎独自のPDF登録は保持します。シートとの常時同期は行いません。
詳細は[共通教材カタログの説明](docs/共通教材カタログ.md)を参照してください。
現在の対象範囲は[指定フォルダー限定の教材カタログ](docs/scoped-material-catalog.md)、
追加情報と登録保留の行は[Excelシートの追加カタログ](docs/excel-sheet-catalog.md)を参照してください。

右上の「PDF教材を登録」で教材名・別名と問題番号→PDFファイル名・ページの対応表を保存します。
既存の教材はプルダウンから編集できます。設定は `%LocalAppData%\AutomaticTestPrinting\pdf-materials.json`
に保存され、更新時は `.backup` を作成します。登録するPDFはメイン画面の教材フォルダー内に置きます。
絶対パスは保存せず、配下をファイル名の完全一致で検索します。同名PDFが複数ある場合は自動選択しません。

レポート読込後、教材名・別名（空白等を除いた完全一致）が一致する依頼はPDF対応表で検査します。
指定範囲に含まれる全番号が登録済みなら、指定問題数を無重複で抽選して番号順に抽出します。
「一括PDFを作成」はExcelとPDFを同じ印刷用PDFにまとめ、レポートごとに「全テストの問題 → 全テストの解答」の順で並べます。
解答を登録しない教材は問題のみ、段階突破は問題・解答一体の原本全ページを一度だけ含めます。
詳細は [レポート単位の印刷順](docs/report-order-printing.md) を参照してください。
PDF教材を含む一括PDFではテストごとに両面用の白紙を挿入します。

段階突破は、たとえば `段階突破 国語（古文） 2020年度 日大 第2回` という教材名を読み取ります。
表示された名前で登録し、問題番号1・ページ空欄（全ページ）に設定します。
科目・年度・段階・回をすべて原本と照合してください。判読できない依頼の自動選択はしません。

詳しくは [PDF教材の使い方](docs/PDF教材の使い方.md) を参照してください。

## PDF教材（手動指定版）

メイン画面右上の「PDF教材から作成」から利用できます。
ページ番号はPDFビューアーの番号を指定し、空欄は全ページを使います。
問題・解答は別々の一括PDFにします。元PDFは上書きせず、プリンターへの自動送信もしません。
未登録教材はこの手動指定画面でも利用できます。登録済み教材は通常のレポート読込から自動作成できます。
詳しくは [PDF教材の使い方](docs/PDF教材の使い方.md) を参照してください。

## 教材設定

対応教材は `materials.json` で管理します。
同じExcel形式の教材は、画面右上の「教材を登録」から追加できます。
利用者がJSONを直接編集する必要はありません。登録時にはマクロを無効にした状態で
Excelを読み取り専用で開き、選択した既存教材と同じシート構成かを確認します。

追加設定は `%LocalAppData%\AutomaticTestPrinting\materials.json` に保存され、
2回目以降の保存時には直前の設定を `materials.json.backup` に退避します。
配布版を更新しても、追加登録した教材は引き継がれます。

設定ファイルには、教材名の候補、Excelファイル名の一部、最大範囲・問題数、
シート名、範囲入力セル、PDFレイアウトなどを記録します。起動後の読み取り時に
必須項目、数値、教材IDの重複を検査し、不正な設定は日本語のエラーとして表示します。

既存教材とシート構成や動作が異なるExcelは、新しい形式の解析と処理エンジン追加が必要です。

教材ファイルは、`ターゲット1900（6訂版）_テスト作成.xlsm` のように
「正式な教材名＋用途」で命名することを推奨します。アプリは教材名を含むファイル名を使って
対象Excelを検索するため、教材名のない汎用的なファイル名は避けてください。

PDF教材の抽出と実プリンターへの印刷は今後の段階で追加します。

OCR結果は誤認識の可能性があるため、印刷処理を接続するまでは原本PDFとの確認を必須とします。

## 技術構成

- C# / .NET 10 LTS
- WPF
- Windows 11 x64
- Excel 2021 64bit
- xUnit

## プロジェクト構成

```text
src/AutomaticTestPrinting.App           WPFアプリ
src/AutomaticTestPrinting.Core          共通モデル・検査・設定保存
tests/AutomaticTestPrinting.Core.Tests  自動テスト
```

## 開発

```powershell
dotnet restore
dotnet build
dotnet test
dotnet run --project src/AutomaticTestPrinting.App
```

## Windows試験配布版の作成

Windows 11 64bit向けの自己完結型アプリをZIPにまとめます。.NETの別途インストールは不要です。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Publish-Distribution.ps1
```

成果物は既定で `artifacts/distribution` に作成されます。配布版には教材、レポート、生徒情報を含めません。

教材、レポート、生徒情報を含むファイルはGitHubへ追加しないでください。

## 同名Excelが複数ある場合

教材フォルダーは「フォルダーを追加」ボタンに加え、エクスプローラーから一覧へのドラッグ＆ドロップでも追加できます。複数フォルダーを一度に追加でき、設定は次回起動にも引き継ぎます。登録済みのフォルダー、ファイル、利用できない項目は追加しません。フォルダーやファイルの移動・コピーは行いません。追加後はレポートの読み取りをやり直してください。処理中は追加を受け付けません。

- 登録ファイル名との完全一致のみを対象とし、別の版・派生語版へは自動で切り替えません。
- 同名ファイルがバイト単位で同一（SHA-256で照合）の場合は、コピーを自動選択します。Excelの見た目が同じでも保存状態などが異なれば、内容の異なる候補として扱います。
- 同名で内容が異なる場合は、レポート確認欄の「使用Excelを選ぶ・変更する」を押して候補の保存場所を確認し、使用する1件を選択してください。同じ教材のほかの依頼にも適用します。
- 選択はローカルの `workbook-choices.json` に、教材フォルダーからの相対パスと内容照合値で保存します。次回起動でも引き継ぎます。ほかのPCには自動共有されません。
- 教材フォルダーの起点が変わっても、その下の階層と内容が同じなら再利用できます。選択したファイルの移動・内容更新時は再選択が必要です。
- 照合に失敗した場合は停止します。クラウド上のファイルは初回照合でダウンロードが発生することがあります。アプリ起動中はサイズ・更新日時が変わっていないファイルの照合結果を再利用します。
- 選択操作で教材ファイルの変更、削除、マクロ実行、印刷は行いません。
- 選択画面は読み取り済みの候補から開きます。保存・内容照合は背景で実行し、選択した教材の依頼だけを再確認します。この操作では教材フォルダー全体の再検索や、ほかの教材の再検査は行いません。PDF作成前は通常の事前検査でファイルを再確認します。
