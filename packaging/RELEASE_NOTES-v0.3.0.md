# 確認テスト自動作成 v0.3.0 実地試験版

2026-10-08の実地試験向け配布版です。

- Excel・通常PDF・段階突破の共通教材カタログを同梱
- Excelシートの追加調査情報を反映（情報不足・不整合は登録保留）
- 登録済みPDFの問題番号・ページ対応から作成
- 段階突破の二重読み取り防止、PDFの照合改善
- レポートごとに問題・解答の順で一括PDF作成
- 国語教材の縦書きレイアウト
- 読み取り・作成中の待機表示
- 教材フォルダーのドラッグ＆ドロップ追加
- Excel・PDFとも科目別フォルダーを優先し、国立校側を参照しない

## ダウンロード・起動

下のAssetsから `AutomaticTestPrinting-v0.3.0-win-x64.zip` を選び、必ず「すべて展開」してから `AutomaticTestPrinting.App.exe` を開いてください。
`Source code (zip)` や `Code → Download ZIP` はアプリ配布版ではありません。
インストーラーではなくポータブル版です。同じWindowsユーザーの設定・追加登録は引き継ぎます。

## 注意

Windows 11 x64、Excel 2021 x64が必要です。.NETの追加インストールは不要です。
電子署名はありません。校舎PCのセキュリティ設定によって起動が止められる場合があります。
自動テストは実施済みですが、校舎の実プリンターでの印刷・全教材の動作は未検証です。
まず少数のレポートで試験し、OCR結果・PDFの指定問題・解答・印刷設定を確認してください。
教材本体・レポート・生徒情報は配布物に含めません。
