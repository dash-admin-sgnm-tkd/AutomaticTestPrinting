## 確認テスト自動作成 v0.2.0 試験配布版

校舎PCで本番環境の動作確認を行うための更新版です。

### 主な変更

- Google Drive・OneDrive・PC内の教材フォルダーを複数登録可能
- 教材Excelの一括スキャン・一括登録
- 教材名・ファイル名・完成形式の検索
- 完成形式の簡易プレビュー
- 英単語・文法・国語教材の完成形式判定を改善
- OCRで範囲番号に混入する不要文字を自動除去
- 未対応教材のスキップとスキップ一覧CSV
- エラー内容を詳しく記録するCSV
- 問題一括PDF・解答一括PDFの作成

### 動作環境

- Windows 11 64bit
- Microsoft Excel 2021 64bit
- Google Drive for desktop（Google Driveを利用する場合）

.NETの追加インストールは不要です。配布用ZIPを「すべて展開」してから `AutomaticTestPrinting.App.exe` を起動してください。

### 注意事項

- プリンターへの自動送信はまだ行いません。作成された一括PDFを確認してから印刷してください。
- OCR結果と作成された問題・解答は、必ずレポート原本と照合してください。
- 電子署名がないため、校舎PCのセキュリティ設定によって起動が止められる場合があります。
- 教材、レポート、生徒情報は配布ファイルに含まれていません。
