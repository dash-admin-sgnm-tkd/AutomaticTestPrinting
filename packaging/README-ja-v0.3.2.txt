確認テスト自動作成 0.3.2（実地試験版・2026-11-18）
================================================

■ 起動・更新方法
1. GitHubのReleasesから AutomaticTestPrinting-v0.3.2-win-x64.zip をダウンロードします。
   「Code → Download ZIP」は開発用のソースなので選ばないでください。
2. 開いている旧版アプリを閉じます。
3. ZIPを右クリックし「すべて展開」を選び、新しいフォルダーへ展開します。
4. 展開したフォルダーの AutomaticTestPrinting.App.exe を開きます。
   インストーラーではなく、展開して使う形式です。.NETの追加インストールは不要です。
5. 同じWindowsユーザーなら、フォルダー設定・追加教材の登録は引き継がれます。
   別のPCでは教材フォルダー、レポートの「01_未処理」、出力フォルダーを初回設定します。
   同梱のJSONファイルは移動・削除せず、アプリと一緒に置いてください。

■ 必要な環境
Windows 11 64bit / Microsoft Excel 2021 64bit
Google DriveやOneDriveを使う場合は、その同期アプリと教材へのアクセスが必要です。

■ 実地試験の手順
1. 教材フォルダーは①英語などの科目別フォルダーを含む場所を指定します。
   国立校で始まるフォルダーにしかないファイルは、この版では参照しません。
2. まずレポート1件で読み取り結果と原本を確認します。
3. Excel、通常PDF、段階突破をそれぞれ少数ずつ作成し、問題・解答を確認します。
4. PDFのページ対応は既存の対応表を使います。異なる版や構成の場合は印刷を止めます。
5. 一括PDFはレポートごとに「問題 → 解答」の順です。
   両面印刷で次のテストと混ざらないための白紙が入る場合があります。
6. 一括PDFを確認してから、PDFビューアーで白黒・両面・部数を設定して印刷します。
   プリンターへの自動送信は行いません。

■ 教材カタログ
Excel・通常PDF・段階突破の情報を同梱しています。
カタログへの掲載と、自動作成への対応は別です。未検証の教材は自動有効化していません。
教材の追加・修正は画面の登録機能を使ってください。
同名ファイルは科目別・段階突破フォルダーを優先します。優先側にも複数あり内容が異なる場合は自動選択を止めます。
以前選んだExcelが参照対象外になった場合は、「使用Excelを選ぶ」で再選択してください。
登録したファイル名と完全一致するファイルを使うため、教材ファイルを勝手にリネームしないでください。

■ エラー・安全上の注意
出力フォルダーの詳細エラーCSVとスキップCSVを確認してください。
このアプリは電子署名がありません。Windowsのセキュリティ設定で起動が止められた場合は、
セキュリティ機能を無理に解除せず、画面とメッセージを開発担当者へ連絡してください。
教材原本は変更しません。このZIPに教材本体・生徒情報・レポートは含まれていません。

■ v0.3.2のPDF範囲設定
通常PDF49教材に対応表があります。STEP・部・学部がある教材は、それらを含む登録名を選んでください。
阪大の国語15カ年 第3版は2008～2022の実年度、きめる！共通テスト現代文はSECTION番号で指定します。
資料待ちの教材には具体的な保留理由を表示します。詳細な更新内容は同梱のRELEASE_NOTESを確認してください。
