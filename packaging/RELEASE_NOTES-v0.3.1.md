# 確認テスト自動作成 v0.3.1 実地試験版

- 読み取り結果を生徒名と確認状態の一覧にし、クリックで詳細を開いて修正できるようにしました。
- 教材名の修正候補を今後の読み取りにも適用できます。Excelの選択・登録エラーに原因や再設定の案内を表示します。
- ターゲット1400（5訂版）の動作確認済みExcelに対応しました。
- Vintageは元Excelの列幅と見出しに合わせたA4縦・1ページ25問で、最大100問まで作成できます。
- 英文法ポラリス1〜3、大岩の超基礎文法編、肘井学のゼロから英文法、高校基礎 英文法パターンドリル、英文法レベル別問題集3、Next Stage 4th、Scramble 4th、英文法ファイナル問題集 標準編は、教材ごとの元Excelの書式に沿って問題・解答PDFを作成します。
- レポートから作成するPDF教材は、出力フォルダーの直下に保存します。同じページに複数の指定問題がある場合は、そのページを一度だけ出力します。
- 配布版の .NET ランタイムとPDFライブラリが使用する暗号化関連の依存関係を修正版に更新しました。

## 更新方法

下の Assets から `AutomaticTestPrinting-v0.3.1-win-x64.zip` をダウンロードしてください。旧版を閉じ、ZIPを「すべて展開」して `AutomaticTestPrinting.App.exe` を開きます。同じWindowsユーザーの設定と教材登録は引き継がれます。

Windows 11 x64とExcel 2021 x64が必要です。ZIPにはアプリ、教材カタログ、説明書が含まれます。実地試験版のため、紙に印刷する前に問題と解答をPDFで確認してください。
