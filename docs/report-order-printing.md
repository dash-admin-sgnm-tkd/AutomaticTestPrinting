# レポート単位の問題・解答一括PDF

## 印刷順

メイン画面の「一括PDFを作成」は、次の順で一つの印刷用PDFにまとめます。

1. レポートAの全テストの問題（画面のテスト順）
2. レポートAの全テストの解答（同じテスト順、解答があるもののみ）
3. レポートBの全テストの問題
4. レポートBの全テストの解答
5. 以下、読み取り結果のレポート順で繰り返す

生徒名やファイル名だけでグループ化せず、レポートの元ファイルのフルパスで区別します。同じ生徒の別レポートや、別フォルダーの同名PDFを混ぜません。

段階突破は元PDF全ページを問題側に一度だけ含めます。原本に含まれる解答を抽出・分離したり、解答側に二重追加したりしません。解答未登録の通常PDF教材は問題だけです。

## 両面印刷と失敗時

PDF教材を一件でも含む場合の両面用白紙調整は従来どおりです。各個別PDFの境界で次のPDFが表面から始まるように必要な白紙を挿入します。これは問題と解答の間にも適用されます。末尾には調整用白紙を付けません。

スキップ対象・作成失敗したテストは含めず、作成成功したテストのみ結合します。失敗件数と詳細ログの表示は維持しています。既存の一括PDFは上書きしません。過去の問題一括／解答一括PDFは削除しません。

作成後のボタンは「印刷用一括PDFを開く」に一本化しています。内容を確認してから印刷してください。アプリからプリンターへの自動送信は追加していません。

## 検証

レポート順、問題と解答の順、同名レポートの区別、解答なし／段階突破、白紙調整、上書き防止、原本保持、欠落ファイルを回帰テストで確認しました。

`tools/ReportBatchPreview` は合成サンプルを本番と同じ結合サービスで処理します。問題A・段階突破A・解答A・問題B・解答Bの順と、間の両面用白紙をPDF抽出およびページ画像で確認しています。実際のレポートの通し作成と実印刷は別途確認が必要です。
