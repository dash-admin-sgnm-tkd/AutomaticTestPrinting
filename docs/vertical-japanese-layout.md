# 国語・漢字の縦書きレイアウト

国語形式（`japanese-vocabulary` または既存の上下解答欄フラグ）を、A4横向きの縦書き表に変更。

- 左から右へ問題を配置。各列は上から「横書きの問題番号」「縦書きの問題」「縦書きの解答／空欄」。
- 講師用には青色の解答を表示。生徒用は解答欄が空欄であることを確認して出力。
- 標準25問／ページ。文章が長い場合は8pt未満にせず、列数を減らして改ページ。
- 番号・問題・解答は同じページに保持。原本のセル内容・書式・印刷範囲は一時コピー内でのみ変更し、原本は保存しない。
- 英語形式の表には適用しない。国語教材を誤って英語形式で登録していた場合は、教材登録で国語形式を選び直す。

確認用ツール `tools/VerticalLayoutPreview` は新しい空白Excelブックに本番と同じ描画処理を適用し、25問の講師用・生徒用、50問、長い解答のPDFを出力する。元ファイル・マクロ・プリンターは使用しない。

2026-10-04：Excel COMによる4種類のPDF出力、Popplerによるレンダリング、講師用・生徒用・複数ページ・長文の目視確認を実施。実教材ごとのデータ選択と実印刷は別途確認が必要。
