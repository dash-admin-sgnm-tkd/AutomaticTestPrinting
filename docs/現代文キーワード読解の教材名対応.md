# 現代文キーワード読解・通常版の教材名対応

2026年11月18日対応。

エラーログの「現代文キーワード読解（キーワード）」は、共通カタログ上の名前と作成設定の別名が繋がっておらず、作成設定未登録と表示されていた。

- 通常版の作成設定「現代文キーワード読解（意味解答）」へ「現代文キーワード読解（キーワード）」を別名として追加した。
- 使用Excelは `現代文キーワード読解(通常はこちら_1~160).xlsm`。問題・意味の160件があり、作業用コピーで50問の問題・解答PDFを出力確認した。
- ログの範囲73-87・10問で、確認画面と同じ判定が成功した。
- このPCに保存されていた別教材への誤った選択2件は、ユーザーの「語句の意味を答える通常版」という回答に基づき修正した。修正前の設定はバックアップした。
- 裸の「現代文キーワード読解」や用途不明の表記を、全PCで意味解答へ自動決定する変更はしていない。要約版とは区別する。
- 自動テスト245件・ビルド成功。GitHub・配布版は未更新。

PDF教材の範囲設定は、作業フォルダの `output/PDF教材_範囲設定未完了一覧.tsv` に別途整理した。
