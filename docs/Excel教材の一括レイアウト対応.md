# Excel教材の一括レイアウト対応

今回、未対応の `.xlsm` 218ファイルを調査し、138ファイルの作成設定を追加した。既存分と合わせて内蔵設定は215件。
以前に対象外とした旧 `.xls` や、対照表などの `.xlsx` は今回の218件に含めない。

## 作成できる形式

- 単語・熟語の短い一問一答：縦向き50問／ページ。日本語から英単語を答えるものは問題欄を広くする。
- 穴埋め問題：縦向き25問／ページ。
- Vintage・ファイナル演習ポラリスの別ファイル：25問／ページ。調査済みポラリスの小問分割も維持する。
- 理社・文法・英作文などの文章問題：文章量に合わせて25・10・5・3・2問／ページ。
- 国語の語句・意味解答：既存の縦書き形式を使い、右側から配置する。文章量によって列数とページ数を調整する。
- 国語の文章形式は右詰めで配置する。

問題と解答は独立して文字を調整する。元データの下線・太字・斜体・上付き／下付きの文字装飾は、文字列内の書式情報から引き継ぐ。
元ブックの標準フォントによる列幅の差も補正して横方向へのはみ出しを防ぐ。
作業用コピー内に新しい出力シートを用意するため、保存済みの非表示行や元シートの保護、印刷ボタンが出力へ混ざらない。
元Excel・元マクロは変更しない。

## 番号・派生語の扱い

教材ごとに元データの番号列・問題列・解答列を設定し、旧形式も同じ操作で作成する。
欠番や問題・解答が欠ける行は候補数から除く。

派生語の5ファイルは、同じ元番号に複数の派生語が登録されている形式として扱う。
入力範囲は元の単語番号のままで、その範囲に属する派生語から抽選し、紙面には枝番を付ける。
たとえば元番号1に4語ある場合、表示は1(1)〜1(4)となる。
通常教材名から派生語版へ自動で切り替えない。

システム英単語・ターゲット1900の派生語は、2022年版と2025年版の問題・解答が同一であることを照合した。
短い教材名では新しい日付のファイルを既定とし、日付入りの名前で旧ファイルを明示指定することもできる。
内容の異なる版を推測で代用しない。

単元指定版の速読英熟語3ファイルは、対応リストから単語番号へ変換する。世界史マルチトレーニングSTEP1の2ファイルはテーマ番号で範囲を指定し、紙面にもテーマ内番号を表示する。いずれも元Excelの対応表と全範囲を照合した。

## 未対応80ファイルの扱い（対応対象16・資料待ち64）

| 理由 | 件数 | 次に必要なもの・確認 |
| --- | ---: | --- |
| 図・冊子の参照が必要な問題を含む | 35 | 図を含む問題PDF、または参照元資料の確認 |
| 解答・章番号だけで問題文の一覧がない | 28 | 問題文を含むExcel、または問題PDF |
| 問題・解答の組や元シート・列を特定できない | 10 | 出題元と列構成の個別確認 |

| 自動回復ファイル | 2 | 通常の元ファイルを優先する |
| ファイルを読み取れない | 1 | 正常なコピーの再取得 |
| 単元対応表が重複・不連続になっている | 1 | 読み解き古文単語の単元37の対応を確認する。通し番号の既存ファイルは利用できる |

追加資料が必要な64ファイル（図・冊子35、問題文不足28、正常ファイルの再取得1）は、ユーザー指示により個別対応リストから除外した。全体一覧には「保留（追加資料が必要）」として理由を残す。残る16ファイルを調査・対応の対象とする。資料待ちの教材は、一覧を再生成しても個別対応リストに戻さない。問題文や図を推測して補わない。

## 検証範囲

追加138ファイルの全165,340件の問題・解答を元データと照合した。
実際のPDF出力は、共通形式の代表27教材で、問題・解答の両方、改ページ、紙の向きを確認した。
単元・テーマ指定の5教材は全324範囲の所属問題と候補数も照合した。自動テスト243件、アプリのビルドも成功している。
各教材の全範囲を個別に印刷確認したという意味ではない。実運用で異常が出た場合は、教材名・範囲・問題数とエラーログで対象を絞り込む。

調査結果は作業フォルダーの `output/Excelレイアウト一括対応一覧.tsv` と
`output/Excelレイアウト_個別対応が必要な教材.tsv` に保存する。

## 個別対応1：日本史一問一答 完全版（3rd・新課程）

2026年11月18日、`3rd(新課程)]日本史一問一答 完全版_20241022本部.xlsm` の対応を追加した。

- 元Excel「問題解答リスト」のF列を抽選用の通し番号、B列を紙面に載せる番号、D列を問題、E列を解答として使う。
- 入力範囲は1〜3493の通し番号。元Excelの操作シートにある「範囲」欄と同じ単位。項目番号や `49-9①` のような表示番号をそのまま入力する方式ではない。
- 全3493問の問題・解答を照合。後続の空行に残った番号は出題しない。
- 1ページ10問、最大100問。100問出力で問題・解答とも各10ページになることを確認した。
- 難易度はA・B・Cを混ぜて出題する。難易度別の指定はこの設定には含めない。
- 通常の元Excelは変更していない。GitHub・配布版は未更新。
