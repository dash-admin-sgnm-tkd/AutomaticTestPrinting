# 共通教材カタログ（2026-10-03試行版）

アプリの「教材カタログ」でExcel・通常PDF・段階突破をまとめて検索できます。

## 含まれる情報

| 種類 | 候補数 | 自動作成の扱い |
| --- | ---: | --- |
| Excel | 343 | 既存の7教材と校舎で追加した作成設定を継続利用。調査一覧だけでは新しい形式を自動有効化しない |
| 通常PDF | 861 | 単純な番号で指定でき、共有ページがなく、ページ対応確認済みの13教材を内蔵 |
| 段階突破 | 320 | 条件に候補が一つの304件を内蔵。候補重複の16件は使用ファイルを選んで登録 |

候補数はファイル・教材レコード数です。同じ参考書の版違い・用途違いは別の候補になります。
Excelの読めなかった2ファイルはユーザーの指示で対象外にしています。

## 初期設定と使い方

1. 教材フォルダーを設定する。Google Drive for desktop・OneDrive・PC内のフォルダーを複数指定できる。
2. 「教材カタログ」で教材名・科目・版・ファイル名を検索し、登録状況・注意点を確認する。
3. 必要なら「選択教材の登録・修正」へ進む。Excelは名前・別名を引き継ぐが、使用ファイル・形式・上限は確認して登録する。PDFは確認済みの対応表を引き継げる。
4. レポートを読み込み、依頼を原本と照合してからPDFを作成する。

段階突破のキーは「段階突破 科目 年度 段階 第N回」。範囲1-1・問題数1で全ページを出力し、解答を別出力しない。
通常PDFは問題番号の範囲から指定された問題数を抽選する。解答編の対応は今回の内蔵データには含めていない。
PDFはファイル名で検索し、同名ファイルが複数ある場合は停止する。通常PDFは想定総ページ数も照合する。総ページ数一致だけでは版・内容一致の証明ではないため、初回は原本を確認する。

## 設定の保存と更新

- 同梱ファイル：`shared-material-catalog.json`。JSONはメタデータだけで、Excelや教材PDFの原本は含まない。PC固有の絶対パスは保存しない。
- 校舎ごとのExcel登録：従来どおりLocalAppData内の`materials.json`。
- 校舎ごとのPDF登録：LocalAppData内の`pdf-materials.json`。共通カタログより校舎で登録した設定を優先し、保存時にはバックアップを作る。
- 変更していない内蔵PDFの設定は校舎JSONへ複製しない。内蔵設定の更新が反映されるようにする。
- スプレッドシートとは常時同期しない。今回は2026-10-03に取得したスナップショットを同梱している。将来のシート変更はカタログの再生成・アプリ配布、またはアプリ内の個別登録で反映する。

共有ページ、複合番号（STEP1問題1など）、番号未確定、ルート表との照合待ちのPDFは自動有効化していない。確認した上でアプリ内のPDF登録から対応表を追加する。
実印刷・実教材による全件動作確認は未実施。今回の検証はビルドと、自動テスト用に生成したPDFによるページ抽出・照合・設定互換性のテスト。
