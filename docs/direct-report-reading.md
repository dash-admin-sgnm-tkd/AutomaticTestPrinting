# レポートの文字情報を優先する読み取り

## 読み取り方式

- 位置情報付きPDF文字抽出（PdfPig、無料、ローカル処理）をページごとに試す。
- 表の列・行の位置を保持して既存の抽出処理に渡す。前回の宿題ではなく「次回までの宿題」を対象とする。
- 文字のないスキャン、文字化け、短すぎる文字情報、表を読み取れないページはWindows OCRへ切り替える。
- ページの使用方式を読み取り結果に「PDF文字抽出／OCR」で表示する。
- 直接文字抽出ではテスト依頼欄が空白の教材を追加しない。OCRで問題数が読めない場合は、従来どおり問題数が空欄の要確認候補を残す。
- 範囲の桁数・問題数は推測で変更しない。旧ターゲット1900専用の桁修正も撤去。全角・区切り記号の正規化は継続する。

## 教材名の確認

- 内蔵カタログと利用者が登録したExcel/PDF教材から、似た名前を最大5件提示する。
- 候補の選択だけでは教材名を変更しない。「候補を確認して適用」の確認で利用者が確定する。
- 元の読み取り文字列は保持する。候補はあくまで文字列の類似であり、版や教材の一致を保証しない。
- 段階突破に類似候補は出さない。科目・年度・段階・回の違うファイルの誤選択を避ける。
- 教材名を変更しても範囲・問題数は変更しない。

## 状態表示

- 登録と不一致：原本の教材名・版・略称と照合し、必要なら教材を登録する。
- 修正候補あり：誤読・略称の可能性として候補を確認する。
- PDFカタログ登録済み・設定未完了：問題番号とページの対応、使用ファイルなどを登録する。
- 設定済みだがファイルが見つからない／範囲に未登録番号がある：既存の具体的なエラーを表示する。

## 確認

2026年5月28日の実レポートは、依頼5件の教材名・範囲・問題数が原本と一致した。SUPREMACYの20題、範囲11-15、1題も直接取得した。第2ページはOCRへフォールバックした。

これは読み取りの確認であり、全教材の印刷対応完了ではない。古文上達のページ対応設定、未掲載のSUPREMACYの登録は別途必要。

印刷、マクロ実行、利用者設定ファイルの書き換えは検証中に行わない。

自動テスト157件通過。既存のスキャンレポート5件はOCRへ切り替わり、前回検証時と同じ候補件数・段階突破の検出結果を保持した。OCRの空欄候補・未解消の誤読まで解消したという意味ではない。

PDF文字の位置情報は[PdfPigの公式ドキュメント](https://github.com/UglyToad/PdfPig)に基づいて使用している。API呼び出しやAI従量課金は不要。
