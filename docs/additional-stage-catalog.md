# 追加段階突破フォルダーの一括登録

## 原本と保存方式

調査対象は、校舎が指定した次のフォルダー配下のPDFです。

`G:\マイドライブ\テスト自動作成\確認テスト\⓪段階突破テスト`

原本は移動・リネーム・変更しません。絶対パスはアプリの教材情報には保存せず、校舎PCでこのフォルダーを教材フォルダーとして追加します。

登録情報は `src/AutomaticTestPrinting.Core/Configuration/additional-stage-catalog.json` に保存し、アプリに同梱します。既存の共有カタログおよび利用者のPDF登録設定を維持し、追加分だけを読み込みます。Googleスプレッドシートへの書き込みはしていません。

## 登録基準

2026-10-04の調査では、PDF 1,257ファイルから685種類の識別情報を抽出し、634種類を追加しました。既存44種類を維持し、段階突破の登録総数は678種類です。識別情報に対してファイルのSHA256が異なる7種類は保留しました。補助資料・別版・識別不十分な562ファイルも自動登録していません。これらは重複を含むファイル数であり、562種類の未対応テストという意味ではありません。

- ファイル名から科目・年度・段階・回をすべて識別できること。
- PDFとして読み込めて、1ページ以上あること。総ページ数を対応表に保存すること。
- 同じ識別情報の候補が複数ある場合、SHA256がすべて同じであること。異なる内容の候補は保留すること。
- 配点表・解答のみの資料・学研別版・段階のない年度別vol資料などは自動登録しないこと。
- 既に登録済みの識別情報は上書きしないこと。

段階突破は全ページを使用し、問題と解答を分離しません。ファイル名とPDF読込による機械的な確認であり、全問の内容照合や実印刷を検証したものではありません。新しく利用する教材は原本と印刷内容を確認してください。

## 重複PDF

複数の検索フォルダーに同名PDFがあっても、サイズとSHA256が一致する完全なコピーであれば一つのテストとして扱います。内容が違う同名PDFはエラーにし、候補の保存場所を表示します。別年度や別の回への置き換えはしません。

## 再調査

一括登録ツールは `tools/StageCatalogImport` にあります。調査結果は `output/stage-catalog-import-audit.json` に追加・既存維持・保留の区分と候補の相対パスを記録します。カタログの再生成前には元のJSONを保存してください。

調査はPDFの読み取りであり、実印刷や元Excelのマクロ実行は行いません。

## 検証結果

追加カタログ込みの137件の回帰テストとWPF待機画面・段階突破表示の検証が通りました。設定済みの2つの教材フォルダーで、現代文／古文の2020年度・日大・第2回がいずれも全10ページのPDFとして照合できることを確認しました。実印刷は未実施です。
