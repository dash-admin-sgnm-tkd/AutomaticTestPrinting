# 教材フォルダーの参照方針

2026-10-08からExcel・通常PDF・段階突破PDFに同じルールを適用します。

- 登録されたファイル名との完全一致で探します。版や日付の違うファイルには置き換えません。
- パス中に「国立校」で始まるフォルダーがあるファイルは参照しません。コピー側も対象外です。
- 「①英語」「②数学」などの科目別フォルダー、段階突破テストフォルダーの候補を優先します。
- 優先側にも同名ファイルが複数ある場合、内容が同一なら1つを利用します。内容が異なれば自動選択を止めます。
- 国立校側にしか見つからない場合は未検出扱いです。国立校側へのフォールバックは行いません。
- 保存した使用Excelが新しい優先ルールで対象外になった場合、黙って別ファイルに変更せず再選択を求めます。
- 学習レベルの「国立」やファイル名に含まれる「国立校」は、この除外判定には使いません。

一覧の「住所」はフォルダー構成一覧のルートからの相対パスです。アプリは設定済みの教材フォルダーから実際のファイルを探すため、PCごとのドライブ文字や絶対パスの固定は不要です。

元カタログの `sourceRelativePath` は過去に調査した場所を示す出典情報です。この出典やファイルIDを新しい場所のものと偽って書き換えず、新しい住所の照合結果は別の監査一覧に記録します。複数PDFに分かれた教材もファイルごとに照合します。

フォルダー一覧による照合はファイル名・場所の確認です。PDFのページ対応・総ページ数・内容が同じかは別途実ファイルで確認が必要です。今回の変更で教材の自動対応を新たに有効化することはありません。
