# ファイナル演習ポラリスの小問分割

対象：標準・応用・発展レベル（登録ID final-polaris-1〜3）。元のExcelは変更しない。

## 範囲の指定

開始・終了番号は、従来どおりExcel「問題解答リスト」の**元の連番（B列）**を入力する。
その範囲内の複合問題を小問に分け、分割後の候補全体から指定問数を重複なしで抽選する。
印字番号（例：2-3B）や分割後の通し番号を開始・終了欄へ入れる方式ではない。

例：標準の285〜286を指定すると、元の2件を各10問に分割するので20問まで作成可能。
発展の45〜45を指定すると5問まで作成可能。
上限は1回100問、1ページ25問。末尾のページは残りの問数になる。

## 問題・解答の扱い

- 正誤の個数を答える複合問題は、各英文の誤りを訂正する形式に変更する。解答は元Excelの解説を使用する。
- 長文中の並べ替えは、該当する英文を取り出す。選択肢に欠落・ずれのある形式は、並べ替え後の指定位置の語や記号列を直接答える形式に変更する。解答を推測して補完しない。
- 前置詞の空所補充は対象を含む英文・節を取り出す。同じ文に複数の空所がある場合は節ごとに独立した英文に直し、他の小問の解答を問題文へ表示しない。
- 語の削除は、番号で区切られた英文と必要な付随文を保つ。
- 分割対象の問題・解答と印字番号は調査済みデータと照合する。内容の違う版に分割規則を流用しない。一致しない場合は対象番号を含む作成を止め、版の確認を案内する。

教材追加や別版への差し替え時に未知の複合問題まで自動分割する機能ではない。新しい構成は再調査が必要。
