# PDF教材からのテスト作成

## 教材登録してレポートから自動作成

1. メイン画面で教材PDFを保存したフォルダーを追加します。Google Drive・OneDriveでも、PCからファイルを読み込める状態なら利用できます。
2. 右上の「PDF教材を登録」を開きます。
3. レポートに書かれる教材名を入力します。別名があればカンマ区切りで登録します。空白や括弧等は無視しますが、文字の一部だけの一致では選びません。
4. 「問題PDFを追加」でファイルを選び、問題番号をレポートで指定する番号に直します。複数選択時の連番は仮番号です。ファイル名から問題番号を推測しません。
5. 1冊のPDFなら「同じPDFで行を追加」で問題番号ごとのページを登録します。例：問題1→PDFの3-4ページ、問題2→5-6ページ。空欄はそのファイルの全ページなので、1冊のPDFを登録する場合は忘れずにページを指定します。
6. 解答を使う場合は「選択行に解答PDFを設定」でファイルを選び、解答ページを指定します。問題と解答が同じPDFでも登録できます。解答は全問登録するか、全問空欄にします。
7. 「対応表を確認して保存」。ファイルの存在・同名重複・ページ範囲を確認してから設定を保存します。次回起動も引き継ぎます。既存の登録はプルダウンで選んで編集できます。
8. いつものレポート読込を行い、依頼が「PDF連携準備OK」になったことと原本を確認してから「PDFを作成」を押します。

指定範囲の全問題番号を対応表に登録しておく必要があります。範囲から指定問題数を無重複で抽選し、問題番号順に出力します。全問使うなら問題数を範囲内の件数と同じにしてください。抽選結果は個別出力フォルダーの「作成内容.txt」に記録します。

元PDFの絶対パスは保存しません。校舎PCでは同じファイル名の教材を配置し、教材フォルダーを設定してください。設定ファイルは `%LocalAppData%\AutomaticTestPrinting\pdf-materials.json`（更新前の設定は `.backup`）です。別PCへアプリだけ移しても登録情報は移らないので、このJSONも引き継ぐ必要があります。

### 段階突破テスト

レポートで判読できた依頼は、`段階突破 国語（古文） 2020年度 日大 第2回`のような教材名で一覧に追加します。その名前をコピーして登録し、該当PDFを問題番号1・ページ空欄で設定します。解答があれば対応させます。

表示された科目・年度・段階・回を必ず原本と確認してください。OCRが判読できない依頼は自動作成されません。通常の範囲や問題数とは異なるため、段階突破の範囲は1-1、問題数は1のままにします。

## 未登録PDFを手動で作成

メイン画面右上の「PDF教材から作成」を押します。レポート読込やExcelの起動は不要です。

1. 生徒名を入力して「教材PDFを追加」。複数選択できます。
2. 各行の生徒名・教材名・使うページを確認、修正します。
   - 長文など1冊のPDF：`1-3,5`のようにページを指定。
   - 問題ごとに分割済みのPDF：必要なファイルを追加してページは空欄。
   - 段階突破テスト：対象PDFを追加してページは空欄（全ページ）。
3. 解答用のPDFも追加する場合は、その行の「解答」にチェックを付けます。同じPDFに問題と解答がある場合は2回追加し、それぞれのページを指定します。
4. 一覧の上から順に結合されます。分割PDFはファイル名の文字列順で追加されるため、必要な順に追加してください（例：1,10,2と1,2,10は異なります）。不要な行は「選択した行を外す」で削除できます。
5. 両面印刷なら「両面用」にチェック。ファイルの境目に必要な白紙を追加して、次のPDFが新しい用紙から始まるようにします。同じ生徒の分割PDFでもファイルごとに区切ります。
6. 「印刷用PDFを作成」を押し、問題・解答の一括PDFを開いて確認します。
7. PDFビューアーの印刷画面で白黒・両面（通常は長辺とじ）とプリンターを指定します。アプリは自動印刷しません。

## ページ指定の注意

「使うページ」は**PDFビューアー上の1始まりのページ番号**です。教材に印字されたページ番号や問題番号ではありません。表紙があれば番号がずれるため、必ず元PDFで確認してください。空欄は全ページです。重複・範囲外・逆順の範囲は入力エラーになります。`5,1-3`などの指定順はそのまま保持します。

## 保存とエラー

設定済みの出力フォルダーに毎回新しい`PDF教材_日時_識別子`フォルダーを作ります。未設定なら保存先を選択します（この画面で選んだ保存先はアプリ再起動後には引き継ぎません。継続利用時はメイン画面で設定してください）。元PDFや過去の出力は上書きしません。

個別PDFと問題・解答別の一括PDFを保存します。読み込みに失敗した教材は一括PDFに含まれず、警告とCSVエラーログが出ます。失敗件数がある場合はその生徒のテストが欠けていないか確認してください。保護されたPDFや壊れたPDFは処理できない場合があります。

## 現段階の範囲

手動指定画面の出力は、レポートから自動作成する一括PDFとは別になります。どちらもプリンターへの自動送信はしません。原本確認とPDFビューアーでの印刷設定が必要です。
