# 英文読解・和訳の縦向きレイアウト

A4縦向き、1ページ10問。11問なら10問＋1問に改ページする。
左に問題番号と英文、右に解答欄を置く。生徒用は英文の欄を広くし、解答欄を空欄にする。
講師用は和訳・構文解説を表示する。問題と解答の文字サイズはそれぞれ独立して調整する。

## 対応教材

| 教材 | 元Excelの有効な連番 |
| --- | --- |
| 関正生の英文解釈ポラリス2（発展レベル） | 1〜55 |
| 入門英文問題精講 四訂版（20231109本部・縦向き版） | 1〜72 |
| 高校英文読解をひとつひとつわかりやすく 改訂版・基本演習 | 1〜236 |
| 高校英文読解をひとつひとつわかりやすく 改訂版・復習テスト | 1〜51 |

開始・終了欄には問題解答リストB列の連番を入力する。紙面にはC列の問題番号を表示する。
1回の作成上限は100問で、指定範囲内の候補数を超える出題はできない。

問題と解答がない行には連番が1525まで入っているものもあるが、その行は対応範囲に含めない。
登録時の形式判定でも、読解教材は問題・解答がそろった行だけから上限を取得する。

## 原本の扱い

元ファイルやマクロは変更せず、作業用コピーに出題内容と印刷設定を反映する。
問題文の大きな連続空白や空行は詰め、内容の省略や解答の推測は行わない。
解答内のSVなどをそろえるための空白と、内容のある行の区切りは維持する。

入門英文問題精講の同名2ファイルは、有効な問題・解答72件が同一であることを確認した。
登録は元フォルダー直下のファイルを照合情報で指定し、入れ子の複製を別教材として増やさない。
既存の横向き・1ページ5問版とは別の作成設定として管理する。
