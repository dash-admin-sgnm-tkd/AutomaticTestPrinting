# 英文読解・和訳の横向きレイアウト

- A4横向き、1ページ5問。6問なら5問＋1問、10問なら5問＋5問。
- 問題番号・英文・解答を左右の表に配置し、問題と解答を同じ順番で出力する。
- 生徒用は英文の欄を広くし、解答欄は空欄にする。講師用は和訳・構文解説の欄を広くする。
- 長い英文や解答は折り返し、必要に応じて文字を小さくして同じ高さに収める。
- 開始・終了番号は元Excelの問題解答リストの連番（B列）。紙面には教材の問題番号（C列）を表示する。
- 作成上限は100問。ただし、指定範囲の有効な問題数を超える問数は作成できない。
- 元Excelやマクロは書き換えず、作業用コピーに出題内容と印刷設定を反映する。
