# レポートの段階突破依頼とPDF連携

- レポートの段階突破依頼は作成カードとして一度だけ表示します。抽出できた依頼の下部要約は非表示にし、抽出できない記載は確認用に残します。
- カードの見出しは「段階突破テストを作成する」とし、通常テストと区別します。
- 科目の「国語（現代文）／国語（古文）／国語（漢文）」は、段階突破の照合に限って「現代文／古文／漢文」と対応させます。通常教材名は変更しません。
- 年度・段階・回は完全一致が必要です。未登録の段階突破はExcelへ回さず、段階突破PDF登録が必要と表示します。
- 登録済みの段階突破は全ページを問題PDFに含め、別の解答PDFは作りません。
- PDF作成は実印刷とは別です。一括PDFの内容を確認後、印刷してください。

## 2026-10-04の確認

設定済みの「国立校 確認テスト作成／⓪段階突破テスト」には44件のPDFがあり、現代文・古文の段階突破はありませんでした。報告された2020年度・日大・第2回の現代文／古文は、原本PDFを用意して登録するまで作成不可です。別年度・別科目への置換は行っていません。

回帰テストでは表記差の一致、年度・段階・回の不一致拒否、全ページ出力、解答分離なしを確認しています。UI検証では一つの作成カードのみ表示し、未抽出時の要約を残すことを確認しています。実印刷はしていません。
